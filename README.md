# Анализ маржинальности B2B продаж: выявление убыточных транзакций

## Описание проекта
В ходе анализа данных была выявлена критическая финансовая проблема: компания теряла прибыль из-за некорректного применения промокода `GIFT5000`. Общие потери маржи превысили **13 млн рублей**.

## Задачи
- Провести ETL-процесс очистки и обогащения данных (Power Query).
- Выявить аномалии в маржинальности позиций (EDA).
- Визуализировать потери по категориям и товарам.

## Инструменты
- **Excel (Power Query & Power Pivot):** Очистка данных, создание модели "Звезда", вычисления.
- **Python:** Скрипт для генерации исходного датасета (250 000 строк).

## Результаты анализа
Выявлено, что промокод с фиксированной скидкой в 5000 руб. применялся к чекам с низкой стоимостью, что приводило к отрицательной марже. Основные убыточные позиции:
- Защитное стекло
- Кабель Type-C
- Наушники Basic
- Кожаный чехол
